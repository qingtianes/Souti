# 设备兼容与已知情况

- Android 8.0 及以上（API 26+）。
- 支持 arm64-v8a、armeabi-v7a 和 x86_64。
- 需要悬浮窗、录屏、摄像头、通知和前台服务权限，具体权限由所用功能决定。
- 部分 HarmonyOS 设备可通过卓易通运行 Android 版本；录屏授权后偶发未启动时，可关闭功能并重新授权。
- PDF 需要包含可提取的文字层。纯扫描 PDF、复杂跨栏、旋转页面和特殊公式排版建议导入后抽查。
- `.xlsx` 暂不直接支持，请另存为 `.xls` 后导入。
- v1.2.0 新增佛脚刷题 `.xls` 导出：支持从原始 TXT/DOCX/PDF/XLS 临时转换；PDF 题干、答案和选项图片会写入导出文件，但佛脚刷题版本对图片显示需以实际导入结果为准。
