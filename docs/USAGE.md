# 使用说明

## 准备题库

1. 打开 Souti 首页的“题库”。
2. 点击“智能导入”，选择 `.txt`、`.docx`、`.pdf` 或 `.xls` 文件。
3. 导入完成后，在题库总览勾选需要参与搜索的题库。

## 浮窗搜题

1. 点击“浮窗搜题”，授予悬浮窗和录屏权限。
2. 将绿色识别框拖动、缩放到需要识别的区域。
3. 结果显示在独立输出窗；拖动标题栏移动窗口，在内容区域上下滑动查看长答案。

## 读屏搜题

1. 点击“读屏搜题”，授予悬浮窗和录屏权限。
2. 应用实时识别屏幕中的多道题并排列结果。
3. 可拖动、缩放或关闭结果小窗。

## 扫描搜题

1. 点击“扫描搜题”，授予摄像头权限。
2. 将内容放入绿色取景框，可捏合或使用按钮缩放。
3. 点击“暂停”锁定当前结果，点击“继续”恢复识别。

## 删除本地数据

在“设置”中选择“清空本地题库与设置”，或通过 Android 系统清除应用数据、卸载应用。
